Website Information

This page provides information about the design, assets, colour scheme, typography, and resources used throughout my portfolio website.

Website Layout

The website uses a simple and organized layout that remains consistent across the different pages. The navigation menu is placed at the top of each page, while the main content is displayed below it.

Desktop Layout

The desktop layout is designed for screens with a minimum width of 950 pixels. Content is centered on the page with clear spacing between sections.

Mobile Layout

The mobile layout is designed for smaller screens. The navigation changes to a vertical layout and content adjusts to fit the available screen width.

Typography

The website uses the Poppins font family from Google Fonts.
